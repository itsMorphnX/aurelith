Download Grimbound

Get the Grimbound launcher. It downloads the game, keeps it up to date, shows the news and patch notes, and still plays the installed game when you are offline.

The launcher

Unzip it anywhere you like (your Desktop or a Games folder) and run GrimboundLauncher.exe.

Download the launcherComing soon

Install in four steps

  1. Download GrimboundLauncher.zip and unzip it into its own folder.
  2. Run GrimboundLauncher.exe. The first time, it downloads the game.
  3. Press Play. The launcher checks for updates each time it opens and keeps the old version until the new one is verified.
  4. No internet? The launcher opens the installed game in offline mode.

Grimbound used to be called Aurelith, so until the next update the launcher is still named GrimboundLauncher.exe.

Windows SmartScreen: Grimbound is a small independent game and is not signed with a paid certificate yet, so Windows may say "Windows protected your PC". Click More info, then Run anyway. Each release lists its SHA-256 checksum on the GitHub release page, and the launcher checks it before installing an update.
